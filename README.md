# 球局剪輯

上傳網球比賽或練球影片，工具會用擊球聲找出每一個回合，剪掉撿球、換邊和休息的空檔，再輸出精華影片。

所有處理都在瀏覽器內完成，影片不會上傳到任何伺服器，也不需要後端或資料庫。

## 運作方式

1. 解碼影片的聲音，經過高通濾波後計算每 8 毫秒的能量。
2. 以局部背景噪音為基準，找出短而尖銳的能量峰值，視為擊球。
3. 相隔不超過「回合間隔上限」的擊球歸為同一回合，再加上前後保留時間。
4. 輸出時把保留的回合依序以即時速度錄製成新影片（MediaRecorder）。

## 限制

- 影片需要有聲音，建議固定機位。
- 輸出是即時錄製，精華多長就要等多久，輸出時分頁需在前景。
- 需要桌面版 Chrome 或 Edge。HEVC 編碼的影片可能無法播放。
- 檔案建議 1.5 GB 以內。

## 開發

純靜態網站，只有 `index.html`，沒有建置步驟。本機預覽：

```
python3 -m http.server 8000
```

部署在 Vercel 時，Framework Preset 選 Other，不需要設定任何指令。
