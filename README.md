# 球局剪輯

上傳網球比賽或練球影片，工具會用擊球聲找出每一個回合，剪掉撿球、換邊和休息的空檔，再輸出精華影片。

所有處理都在瀏覽器內完成，影片不會上傳到任何伺服器，也不需要後端或資料庫。

## 運作方式

1. 解碼影片的聲音，經過高通濾波後計算每 8 毫秒的能量。
2. 以局部背景噪音為基準，找出短而尖銳的能量峰值，視為擊球。
3. 相隔不超過「回合間隔上限」的擊球歸為同一回合，再加上前後保留時間。
4. 輸出時把保留的回合依序以即時速度錄製成新影片（MediaRecorder）。

## 球場標定、球追蹤與球速

1. **標定**：把影片暫停在四個球場角落都看得到的畫面，按「開始標定」，依序點選近端左、近端右、遠端右、遠端左四個角（可拖曳微調）。工具用球場的真實尺寸（雙打 10.97 × 23.77 m、單打 8.23 × 23.77 m）算出透視變換、相機高度與焦距，並在預覽畫面畫出球場線、球網、每 1 公尺刻度與各處的「1 公尺 ≈ N 像素」。標定會存在這台瀏覽器。
2. **追蹤**：按「追蹤每一顆球」，逐格找出黃綠色、會移動的小圓點，用多目標追蹤器同時追多顆球。擊球、彈跳或漏偵測造成的斷點，會依位置與時間自動接成整個回合的連續路徑，在預覽上畫成一條實心線並圈出彈跳點。耗時約等於影片長度。
3. **球速**：每段飛行用重力＋3D 相機射線做拋體擬合（不是單純用地面比例尺，那會因為球在空中而偏差），在擊球聲或彈跳處分段，預覽與「球速」清單顯示約略 km/h。誤差太大的段落不會列出。

準確度提醒：合成資料測試中快球誤差約 2–10%，慢速吊球無法可靠估算。尚未用大量真實影片驗證；空氣阻力、動態模糊、鏡頭畸變與點角誤差都會影響結果，數字請當參考值。

## 測試

```
node test/geometry.test.js
node test/tracker.test.js
```

## 限制

- 影片需要有聲音，建議固定機位。
- 輸出是即時錄製，精華多長就要等多久，輸出時分頁需在前景。
- 需要桌面版 Chrome 或 Edge。HEVC 編碼的影片可能無法播放。
- 檔案建議 1.5 GB 以內。

## 開發

純靜態網站（`index.html` 加上 `lib/` 內的幾何與追蹤模組），沒有建置步驟。本機預覽：

```
python3 -m http.server 8000
```

部署在 Vercel 時，Framework Preset 選 Other，不需要設定任何指令。
